UI 设计规范

以橄榄绿建立品牌识别，暖白构建舒适内容空间，橙色强化价格与购买行为。通过卡片化布局、圆角组件与线性图标，建立统一、轻量、具有消费场景感的移动端视觉体系。

01

Design Principles 设计原则

整体视觉关键词与色彩逻辑，作为后续所有规范的统一出发点。

视觉关键词

自然温暖简洁轻消费高识别

保持界面轻量，减少复杂装饰；商品图片作为主要视觉内容；卡片化组织商品与功能；圆角、留白与图标风格统一。

色彩逻辑

橄榄绿 品牌识别 → 暖白 降低压力 → 橙色 强化消费 → 咖啡棕 饮品场景

绿色统一品牌识别，橙色突出价格与购买行为，咖啡棕补充饮品相关场景氛围。

17

Image Guidelines 图片规范

商品图片是设计系统的一部分，应保证主体完整、背景干净、可复用。

✓ Do

统一比例 · 主体居中完整 · 不裁切 Logo · 背景干净 · 同一商品跨页使用相同图。

✗ Don't

不在商品图里叠加价格 / 文字等 UI 信息；图片只承载视觉，信息交给组件。
