Animal Growth Garden · Gamified Children Growth App

儿童成长乐园

Animal IP × Gamified Growth Experience

从动物 IP 视觉体系出发，建立角色与植物成长体系，通过动效让角色获得生命感，并将 IP 延展到儿童移动端产品，形成学习、任务、积分、成长、成就、奖励的完整游戏化体验。

02

Project Overview

项目概览

Design Goal

让用户通过收集、互动、成长与解锁，建立与角色之间的情感连接。

Target User

儿童 / 年轻用户 / 游戏化产品用户，适合具备成长、收集与奖励机制的产品场景。

Project Output

9 个动物 IP、3 阶段成长系统、动物动态 GIF、植物成长系统、徽章与成就视觉、UI 场景延展。

Role

UI / Visual Design · IP Visual Design · Motion Design · AIGC

03

Design Challenge

设计挑战

01 · 角色如何建立辨识度？

通过动物形态、配色、性格、装饰和标志动作建立角色识别，让每个 IP 都有稳定的记忆点。

02 · 成长过程如何被看见？

通过幼年、少年、成年建立明确的视觉成长反馈，让用户能感知自己的行为带来变化。

03 · 动效如何增强获得感？

通过微动效、互动反馈和解锁动画，让角色从静态视觉资产变成产品体验的一部分。

04

IP Design System

IP Design System

9 个角色，共享统一的视觉语言，同时保持独立性格。

Character System

9 个角色共享统一的造型比例、表情语言、配饰逻辑与动作状态，形成可扩展的角色系统。

9 Roles Unified Language Motion Ready

Character Language

通过统一的比例、表情、体态、配饰与色彩语言，让每个角色既有系统感，又有独立记忆点。

头身比例统一 Q 版比例，放大头部与眼睛，增强亲和力。
表情语言通过眉眼、嘴型和腮红传递情绪。
体态圆润轮廓与低重心，强化陪伴感。
配饰用围巾、徽章、装饰物标记角色身份。
色彩角色主色与乐园环境协调，保持高识别度。
动作用耳朵、尾巴、四肢小幅度动作增加生命力。
