02
Project Overview

项目概览

这是一个面向高校校园场景的自助贩卖机点单界面 redesign。项目以「即时补给」为切入点，梳理扫码、浏览、加购、下单、取货反馈的关键链路，让高频用户在课间、夜间和高峰时段都能更快完成购买。

03
Design Challenge

设计挑战

Challenge 01

课间时间窗口短

学生需要在 3 分钟内完成从选择、加购到结算的完整操作，任何多一步的跳转都会导致流失。

Challenge 02

商品信息识别成本高

原有界面商品信息层级不清晰，价格、口味、库存与购买状态分散，用户需要反复确认。

Challenge 03

高峰与夜间场景压力

教学楼下课高峰和夜间无人值守时段，操作流畅度、反馈清晰度直接影响使用信心。

04
Design Goal

设计目标

更快下单

收敛核心操作，让高频路径保持短、直、可预测。

一眼识别

商品名、口味、价格和加购状态采用统一视觉层级。

场景可用

兼容单手操作、夜间阅读和高峰时段高频点击。

系统一致

沉淀色彩、字体、组件与交互规范，便于后续扩展。

05
User Flow

用户流程

从扫码进入设备，到确认下单并取货，将真实校园消费动线压缩为可快速完成的核心路径。

01 扫码进入 定位当前机器，展示设备状态与推荐商品
→
02 选择分类 饮料 / 零食双分类，减少浏览噪音
→
03 加购商品 数量、价格、库存反馈同步更新
→
04 一键下单 底部购物车常驻，合计实时可见
→
05 取货反馈 下单成功提示清晰，减少二次确认成本
06
Visual Direction

视觉方向

整体视觉围绕「自然、温暖、简洁、轻消费」展开。橄榄绿承担品牌识别，暖白让内容保持轻盈，橙色只用于价格和购买行为，使高频操作在页面中一眼可见。

自然 温暖 简洁 轻消费 高识别
07

色彩系统

品牌绿、暖白、橙色价格强调与咖啡棕场景辅助，构成统一且低干扰的消费感配色。

13
Design Value

设计价值

缩短路径

把加购、合计和下单收敛到同一操作闭环，减少课间场景下的决策时间。

统一语言

色彩、字体、组件与状态反馈形成一致系统，降低后续页面扩展成本。

场景可信

从高峰排队到夜间无人值守，都以清晰的即时反馈支撑用户完成购买。

可演示性

可交互原型让设计逻辑可以被真实点击和验证，方便与开发、业务对齐。
