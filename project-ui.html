UI 设计与交互作品展示

游戏 UI HUD 界面 APP UI 组件规范 交互动效

本项目涵盖游戏主界面、HUD 界面、角色系统、背包系统、商城系统、弹窗设计与 UI 组件规范的完整界面设计作品。以用户体验为核心，注重视觉层次、交互逻辑与动效反馈，打造兼具美感与可用性的数字产品界面。

角色

2025 - 2026

游戏 UI 设计

游戏界面设计注重沉浸感与操作效率的平衡。通过统一的视觉语言、清晰的层级关系与流畅的动效过渡，为玩家打造直觉化的交互体验。

UI 组件规范

建立完整的 UI 组件库，涵盖按钮、卡片、弹窗、导航、表单等基础组件，确保界面视觉一致性与开发效率。

视觉规范

定义色彩系统、字体层级、图标风格与阴影规范，形成统一的设计语言基础。

组件库

构建按钮、输入框、卡片、弹窗、标签栏等可复用组件，标注尺寸与交互状态。

交互动效

为关键交互定义过渡动画与微交互反馈，提升界面的生动感与操作确定性。

响应适配

制定多分辨率适配方案，确保界面在不同设备上的视觉表现与操作体验。
