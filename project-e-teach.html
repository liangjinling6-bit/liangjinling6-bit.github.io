Project Context

真实课堂场景下的授课端

授课端是教师在真实课堂环境中使用的多媒体授课工具，覆盖从进入课堂到教学闭环的核心工作流。

界面设计需要服务一条清晰的教师路径——选班选课、发起互动、查看学生实时状态、回收答题数据并据此调整教学。

  • 进入课堂
  • 选择班级 / 科目
  • 发起课堂互动
  • 学生参与
  • 实时状态
  • 数据反馈

03
Design Challenge

真实产品面对的核心问题

CHALLENGE 01

重点信息不突出

课堂场景下信息密度高，教师需要在短时间内定位关键学情，原有界面层级不够清晰。

CHALLENGE 02

课堂远距离可读性弱

投屏教学时，后排学生与教师均需快速读取数据，图表与分布的可读性需要强化。

CHALLENGE 03

功能入口识别成本高

提问、测试、点名等高频互动入口分散，教师在授课节奏中需要更快进入对应功能。

Design Strategy

四个核心设计策略

01 · Information Hierarchy

信息层级优化

强化重点学情与操作路径的视觉权重，让关键数据在课堂节奏中一眼可读。

02 · Classroom Interaction

课堂互动流程

收敛并前置提问、测试、点名等互动入口，贴合教师真实授课动线。

03 · Visual System

视觉规范统一

沉淀主色、组件与状态规范，让多个教学模块共享同一套设计语言，详见第 09 节设计规范。

04 · Real-time Feedback

实时状态反馈

让学生参与、答题分布与正确率以清晰的状态反馈呈现，支撑教师即时决策，详见第 07 节。

Core UI

核心页面展示

答题设置 · 单题答案分布

从单题答案分布、答题设置，到试卷明细与课堂发起测试，核心页面构成课堂数据闭环的关键界面。

07
07
Real-time Feedback

实时状态反馈

Live Signal

学生提交即更新

每收到一份学生答题，分布柱、正确率与排名同步刷新——教师无需等待收齐即可看到整体趋势。

  • 实时分布作答提交即时反映在柱状图
  • 正确率聚合数据自动计算并以大字号呈现
  • 逐人明细可下钻到每位学生的具体作答

学生参与后的实时分布与状态反馈，让教师无需等待即可调整课堂节奏。

Project Summary

项目总结

智慧课堂是一套已在真实课堂场景落地的教师授课端界面。设计围绕「教师—课堂—互动—学生—实时反馈—数据分析」的教学闭环展开，通过强化信息层级、收敛高频互动入口、统一视觉规范，提升课堂信息的可读性与教师操作的顺畅度。

项目沉淀了以真实主色系统为基础的设计规范，使多个教学模块共享一致的设计语言与组件体系，为后续迭代提供可复用的基础。
